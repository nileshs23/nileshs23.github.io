# Nilesh Solanki | Software Engineer Portfolio

Personal developer portfolio website for **Nilesh Solanki**, Java Backend Engineer at **greytHR** (former Cybersecurity Specialist at PwC).

---

## 🌟 Key Highlights

### 1. Main Portfolio (`index.html`)
- **Modern UI & Aesthetic:** Dark obsidian theme, ambient glows, glassmorphic navigation, and typography (`Plus Jakarta Sans` & `JetBrains Mono`).
- **Interactive Sections:**
  - Hero banner with current role status (`Java Backend Engineer @ greytHR`)
  - Metrics strip (2+ Years Backend Experience, 300+ DSA Questions, 15+ Projects)
  - About section highlighting cloud HRMS & high-concurrency payroll microservices
  - Categorized Technical Skills (Backend 100%, Frontend, Cloud/Databases, Security)
  - Continuous infinite project carousel with spotlight hover effect
  - Interactive Experience & Education timeline with smooth expandable details
  - Direct contact form and social channels

### 2. Recruiter Brief (`recruiter.html`)
- Dedicated, distraction-free page tailored specifically for **Technical Recruiters & Hiring Managers**:
  - Executive Candidate Summary & Fast Facts (Notice Period, Location, Primary Stack)
  - Technical Competency Matrix
  - Recruiter Checklist & Security Credibility
  - Chronological Experience (greytHR & PwC) and verified projects showcase
  - Print-optimized layout (`@media print`) for clean PDF exports
