How to Create Your GitHub Token

To commit and deploy directly from this webpage into your GitHub repository (nileshs23.github.io), generate a free Personal Access Token:

  1. Open GitHub Settings → Personal Access Tokens (Fine-grained).
  2. Click "Generate new token".
  3. Set Token name: Portfolio CMS Token and Expiration (e.g. 90 days or 1 year).
  4. Under "Repository access", select "Only select repositories" → pick nileshs23.github.io.
  5. Under "Permissions" → "Repository permissions", grant:
    • Contents: Access: Read and write.
  6. Click Generate token, copy it, and paste it into the GitHub Sync input above.
100% Client-Side Privacy: Your token is stored only in your browser's private session memory. It connects strictly to api.github.com with no middleman.
