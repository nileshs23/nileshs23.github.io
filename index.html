About Me

Enterprise Backend Velocity with High-Security DNA

Currently working as a Java Backend Engineer at greytHR (Greytip Software) for over 2 years, where I develop scalable microservices powering cloud HRMS and payroll calculation engines handling massive daily employee transaction volumes.

My day-to-day engineering focuses on Java 21, Spring Boot 3, and Apache Kafka for distributed event streaming (attendance regularisation, shift scheduling, payroll cycles), containerized with Docker, backed by PostgreSQL/MySQL and Redis caching.

Previously, I served as a Cybersecurity Specialist at PricewaterhouseCoopers Pvt Ltd (PwC), safeguarding digital assets and auditing enterprise software vulnerabilities. This background gives me a distinct advantage: writing performant backend code that is secure by design from day one.
